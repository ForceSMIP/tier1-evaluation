# tier1-evaluation
Code for evaluating statistical and machine learning methods using the ForceSMIP Tier1 dataset (https://doi.org/10.5281/zenodo.15577519). This method evaluation code serves to document the analysis in Wills et al. (2025, submitted) and provides a workflow for evaluating your own methods against the ForceSMIP Tier1 methods. 

This repository contains:
- MATLAB scripts used for all analysis in Wills et al. (2025, submitted)
- Python code for evaluating the estimated forced trends of the ForceSMIP methods (equivalent to MATLAB script ForceSMIP_trend_skill.m and associated functions).

Further details of the dataset and evaluation methodology can be found in Wills et al. (2025, submitted).
